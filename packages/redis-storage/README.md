# CinaAuth Redis Storage

Redis storage for [CinaAuth](https://www.cinagroup.com) secondary storage — use Redis for session caching and rate limiting.

## Installation

```bash
npm install @cinaauth/redis-storage
```

## Documentation

For setup and usage documentation, see [Redis Storage](https://www.cinagroup.com/docs/concepts/database#redis-storage).
